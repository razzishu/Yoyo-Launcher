# Yoyo Launcher

A clean, fast Android home screen launcher based on LineageOS Trebuchet (Launcher3), decoupled from system dependencies and converted to a standard Gradle project that runs on any Android 12+ device.

## Features

- **Icon Packs & Shapes**: Support for third-party icon packs, custom shape masking (Squircle, Circle, Teardrop, Oval), and icon scaling.
- **Material You Themed Icons**: Support for monochrome and dynamic color palette icons.
- **Grid Customization**: Easily switch between workspace grid layouts.
- **Lightweight & Fast**: Fast app drawer search, smooth animations, and low resource usage.
- **Standalone Gradle Project**: Converted from AOSP/Soong build configuration so you can open and build directly in Android Studio.

## Building

1. Clone the repository:
   ```bash
   git clone https://github.com/razzishu/Yoyo-Launcher.git
   ```
2. Open the folder in Android Studio.
3. Sync Gradle and run on an Android 12+ device or emulator.
